# Discuss

{{$ARGUMENTS}}

Research design decision, discuss with user. Document conclusion.

## Steps

1. If context provided with command (text above): use as starting point. May contain specific question ("should we use X or Y?"), design tradeoff, or reference to discussion requirement in planning files.

2. Read relevant planning files, design docs, codebase to understand decision context.

3. Research available options — docs, best practices, community patterns for each approach.

4. Present findings with clear comparison of options, tradeoffs, recommendation.

5. Discuss and refine based on user feedback.

6. Document decision in appropriate files (update design docs, add decision record, update discussion requirement status).
